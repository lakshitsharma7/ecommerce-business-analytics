# Resume Project Entry

## E-Commerce Sales, Customer & Business Performance Analytics

**Synthetic portfolio project | Python, SQLite/SQL, Excel, HTML/CSS/JavaScript**

- Built a reproducible Python cleaning pipeline for four defect-injected synthetic CSVs, preserving raw inputs and recording corrections/rejections in a JSON audit.
- Loaded cleaned dimensions and fact tables into a constrained SQLite warehouse and executed 32 business-analysis SQL statements plus four validation statements.
- Developed a six-page local dashboard that queries the warehouse read-only and supports year, region, category, sales-channel, and customer-segment filters.
- Compared sales, discounts, line-item profit, customer order frequency, returns, inventory snapshots, and target data while documenting metric definitions and order-status limitations.
- Generated an Excel workbook with formula demonstrations clearly separated from SQL-calculated full-warehouse values, plus an executive report.

### Scope to state accurately in an interview

- The dataset and company are synthetic.
- The interactive dashboard is a browser prototype, not Power BI.
- The PBIX is not usable; the DAX file is a reference only.
- Revenue and line-item profit include all stored order statuses, including cancelled orders.
- Results are descriptive; no causal lift, real-world financial impact, or EBITDA forecast was measured.
